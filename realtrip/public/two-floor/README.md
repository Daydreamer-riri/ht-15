# 双层休息空间

三段实拍视频通过 LoFTR 特征匹配与 COLMAP 联合求解，483/485 帧注册，平均重投影误差 1.152486 像素。Brush 训练 20000 步、细化 4000 步，追加优化 2000 步（累计 26000 步），沿用 SuperSplat 高斯渲染。

楼梯、楼板、栏板与选定桌椅使用独立隐形碰撞；尺度和碰撞尺寸根据视频推测。可视补面只用于局部缺口。没有普通网格替代整场景。

重点优化：补拍相机重新标定，115/116视角接入，覆盖视频开头至下楼；最大缺口1.43秒、平均重投影误差1.13像素。采用26000步基线追加3000步，替代上一轮部分对齐分支；前25秒8倍采样，其余补拍6倍。新增补拍视频起点，碰撞校准不变。近距离栏板和遮挡处仍可能模糊。

二层细节优化：在上一轮正确标定结果上追加3000步，119个原像素局部裁剪重点训练器材和桌椅，相机主点同步校正；保留598完整视角，高斯上限200万。本地更新，未推送部署。

楼梯专项优化：在二层细节版上新增3000步，上楼、回看及下楼视角联合强化踏步/扶手/平台，相机主点同步校正；保留598完整视角，高斯上限240万。本地更新，未推送部署。

一楼楼梯补拍：新增约21秒视频，64/64帧以固定旧相机方式接入，平均重投影误差1.08像素。基于35000步局部合并模型追加3998步，另用2步近零学习率作前后对照，总计4000步；模型训练谱系38998步。64个射线等价裁剪重点补楼梯入口、下段踏步、立柱及花池；仅合入一楼局部，范围外旧高斯字节保持一致，碰撞未改。参考视图为训练见过的视角，不代表未见视角精度；玻璃反射和细杆仍可能模糊。本轮仅更新本地项目。

二楼与楼梯转角补拍：新增约60秒视频，选取180帧、174帧接入，保留662个旧相机位置；总计836/845帧，平均重投影误差1.05像素。新增174个射线等价细节裁剪，转角提高采样权重；追加3996步训练，对照评估2步，总计3998步，模型谱系42994步。仅合入二楼和上段楼梯转角外观，范围外旧高斯逐字节保留；碰撞及出生点不变。参考图来自训练视角，细杆和反射仍可能偏软。本轮仅更新本地项目。

楼梯口栏板与转角细化：重用58.4秒下楼补拍，按更密集时间窗口选取172帧，其中82帧与原抽帧不同，79帧成功补入既有坐标。仅用30秒后的81个视角及对应裁剪重点训练（38个新增不同视角、43个已有画面加权），补正面、后侧、端部栏板、入口接缝、局部上方边框及上段台阶。追加4996步训练和3步对照，总计4999步（上限5000），模型谱系47990步。素材仍为六段独立视频，合计915/927个不同帧注册/选取。仅局部合并，范围外旧高斯逐字节保留；碰撞及出生点保持。参考图为训练见过视角，反射及未覆盖方向仍可能偏软。仅本地更新。
