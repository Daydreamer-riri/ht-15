# 我和小蓝：独立第三人称体验

入口：`/walk-me/`。从 NPC 发布版本 `9eea359` 新增，现有 `/walk/?scene=hackathon-npc` 不切换到这个入口，也不加入主漫游场景菜单。

- 默认第三人称跟随：WASD / 移动端摇杆行走，拖动画面绕人物转动镜头。行走速度在本入口降为 0.65 场景单位/秒，保持原场景的体素地面、墙面、跳跃及角色碰撞。
- `companion-walker.js` 是独立启动入口。会场、碰撞、小蓝模型和语音配置资源继续来自同站点 `../walk/`。`build:companion` 只写 `dist/walk-me/`。
- 导航使用一个不渲染的玩家锚点。跟随相机有体素射线避障，自动适配横竖屏取景；小蓝的靠近、面对访客和碰撞反应使用玩家位置，不使用跟随相机位置。
- `scripts/player-model.mjs` 根据用户授权提供的两张正面照片手工构造风格化立体模型，包含分缝黑发、细金属眼镜、黑色 T 恤（前胸居中偏上吊牌印花、背面右下角 loading 印花）、黑裤和左腕圆表。模型有独立四肢、肘膝和手部节点。它不是照片扫描，侧后方细节是风格化补全。原始照片不发布。
- 玩家依据实际位移转身、摆臂、迈步，停止或碰墙后动画归于静止。挥手按钮同时触发玩家动作和小蓝原有的问候。减弱动态效果设置保留。
- “看看自己”按需加载独立 Three.js 预览，可全身、背面、面部、旋转、缩放和挥手；打开时暂停移动/语音，关闭后释放预览 WebGL 资源。
- 语音识别、识别文字、语音回复和重播沿用已完成的 NPC 服务。此入口的对话通过同一阿里云网关 `/api/npc/chat` 调用千问联网搜索；不再读取浏览器 DeepSeek Key。`npc-search-client.js` 保留取消、超时和错误提示，`companion/npc-sources.js` 提供可展开的来源链接及北京时间检索时间。来源独立于字幕和朗读，新问题或离开时清除。

构建：`npm run build:companion`。模型写入 `realtrip/models/player/`，发布模型和预览脚本使用内容哈希防止缓存错版。完整 `npm run build` 会包含该入口。

验证：`npm run test:walk`、`npm run test:migration`。本次变更不提交旧 `/walk/` 的构建文件；发布新入口应只纳入对应源文件及 `dist/walk-me/`。

衣服印花由用户提供的服装照片整理为透明 PNG，并内嵌到 GLB；贴花网格贴合衣服曲面，随躯干活动。来源与处理记录见 [`prints/README.md`](../models/player/prints/README.md)。
